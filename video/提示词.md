# 提示词手册｜ue_svn_ignore_v1.1 介绍视频

- 用途：配套 `video/视频文案.md`，生成封面、章节承接图、AI 生视频素材与 TTS 旁白
- 工具：即梦、可灵（Kling）、Midjourney、以及任意支持的 TTS（即梦配音 / 剪映 / 火山引擎等）
- 画幅：全部 16:9，1920×1080
- 编码：UTF-8，简体中文

## 使用说明

1. **每个代码块都是完整的、可直接复制粘贴的提示词**；中文块用于中文界面的工具（即梦、可灵、剪映），English 块用于 Midjourney / SDXL / Runway 等英文界面工具。
2. **中英文不要混排复制**：一个代码块内只有一种语言，避免工具解析混乱。
3. 封面与章节卡的**文字不要交给 AI 生成**（容易出现乱码字、假 logo），按提示词出底图，标题文字在剪辑/设计软件里叠加；底图已按「左侧留负空间」构图。
4. 图片出图比例选 16:9；Midjourney 在提示词末尾加参数（见各节「参数」），即梦/可灵在生成设置里选 16:9 或 1920×1080。
5. 所有「负面提示词」单独成块，即梦/可灵可粘贴到负面框，Midjourney 用 `--no` 参数拼接。

## 1. 封面图提示词

### 1.1 设计要点

- 构图：**左侧 55%–60% 为纯负空间**（后期放主标题、副标题），右侧 40% 放悬浮终端窗口。
- 配色：深灰近黑底 `#0E1116`～`#161B22`；强调色青绿 `#3DDC97`（代码/成功）、少量橙色 `#FF8A3D`（警告/标签）。
- 元素：终端窗口 + 模糊等宽代码行（不可读，只做质感）+ 极淡 UE 风格线框网格/立方体 + 轻微屏幕辉光。
- 留白：四周至少 8% 安全边距；画面内**不放任何文字**。
- 分辨率：1920×1080（出图可 2K 再缩，保证锐度）。

## 4. TTS 旁白提示词

### 4.1 音色方案

| 方案 | 音色描述 | 适配版本 | 说明 |
| --- | --- | --- | --- |
| 男声（推荐） | 28–35 岁，中低音，干净、平稳、略带一点「技术讲解」的松弛感；不播音腔、不夸张 | A 版优先 | 与终端/代码画面更搭，可信度高 |
| 女声 | 25–32 岁，清亮但不过甜，语速稳，咬字清楚，情绪克制 | B 版或双人分段 | 长讲解里更耐听，适合教程 |

禁用的音色倾向：过度热情、综艺腔、娃娃音、拖长尾音、每句末尾上扬。

### 4.2 语速与停顿

- 语速：**4.8 字/秒**（约 288 字/分钟）；允许 4.5–5 字/秒浮动，同一版内保持一致。
- 停顿：逗号 0.25s；句号 0.45s；自然段之间 0.6–0.8s；章节卡处留 1.5s 无旁白；A 版 S10（0:42–0:45）与片尾卡严格无旁白。
- 数字与英文：`SVN` 逐字母读「S V N」；`UE` 读「U E」；`bat` 读「批处理」；`DLL` 读「D L L」；`revert` 读「revert」（瑞-沃特，不拆字母）；`PATH` 读「PATH」（帕斯，连读）；`F5` 读「F5」。
- 命令类内容（`/ignore`、`/fix`、`svn revert -R`）在旁白里改用中文说法（忽略模式 / 修复模式 / revert 撤销），命令原文只出现在字幕里，避免 TTS 念错。

### 4.3 TTS 指令（可直接复制使用，中文）

```text
请用一位 30 岁左右的男声朗读下面的技术解说稿。中低音，干净、平稳、可信，像工程师给同事讲工具，不要播音腔，不要综艺感，不要夸张重音。语速 4.8 字每秒，全程保持匀速；逗号停顿 0.25 秒，句号停顿 0.45 秒，段落之间停顿 0.7 秒；数字和英文缩写按字母逐个读（SVN 读作 S V N，DLL 读作 D L L），bat 读作批处理，PATH 连读。遇到「（无旁白）」直接跳过，不要读出括号内容。
```

English version:

```text
Read the following technical narration with a calm male voice, around 30 years old, medium-low pitch, clean and steady, like an engineer explaining a tool to a colleague. No broadcast announcer tone, no hype, no exaggerated stress. Speaking rate: 4.8 Chinese characters per second, constant tempo; 0.25s pause at commas, 0.45s at periods, 0.7s between paragraphs. Read English abbreviations letter by letter (SVN as S-V-N, DLL as D-L-L); read "bat" as "batch file" only if localized, otherwise skip. Skip any parenthetical stage directions.
```

## 5. 字幕与排版规范

### 5.1 字体

- 中文：**思源黑体（Source Han Sans）** 或 **阿里巴巴普惠体**；标题用 Bold/Heavy，字幕用 Regular/Medium。
- 等宽（命令、路径、属性名）：**JetBrains Mono**、**Cascadia Mono** 或思源等宽；只用于代码样式字幕，正文不用。
- 中英混排：中英文之间留 1 个半角空格（如 `7 条规则`、`svn:global-ignores 属性`）。

### 5.2 字号（1920×1080 画布）

| 用途 | 字号 | 占比 |
| --- | --- | --- |
| 主标题（封面/片头卡） | 96–128px | 画面高度 9%–12% |
| 章节卡标题 | 72–88px | 7%–8% |
| 正文屏幕字幕 | 54–60px | 5%–5.6% |
| 注释/角标 | 32–36px | 3% |
| 代码样式字幕 | 48–54px | 4.5%–5% |

### 5.3 描边与阴影

- 字幕统一加 2px 深色描边（`#000000`，不透明度 60%）+ 2px 偏移的柔和投影（`rgba(0,0,0,0.35)`，模糊 6px）。
- 字幕底衬（可选）：黑色圆角条，不透明度 35%–45%，仅用于浅色画面背景；不要全程加底条。
- 强调色：青绿 `#3DDC97` 用于命令/正向结果；橙色 `#FF8A3D` 用于风险提醒（回滚、备份、易错点）。

### 5.4 安全区

- 左右各留 **5%**（96px），上下各留 **10%**（108px）。
- 底部字幕基线放在安全区下沿内侧，避免被平台进度条/推荐栏遮挡。
- 竖屏平台二次分发时，字幕组需重新排布，不要把横版字幕直接裁切。

### 5.5 每行字数

- 中文每行 **≤18 字**（推荐 12–16 字）；最多 2 行，超过就拆条。
- 代码/路径类字幕不强制字数，但单行不超过画面宽度的 70%。
- 长句断行只在标点或语义块处断，不在词中间断。

## 6. 剪辑规范

| 项目 | 规范 |
| --- | --- |
| 录屏分辨率 | 1920×1080，60fps（终端滚动更顺滑）；工程/终端窗口铺满录制区域 |
| 终端字号 | Windows Terminal 20–22pt（或 cmd 字号 24），行距默认；录制前关掉多余标签页 |
| 光标高亮 | 录制时保持光标可见；后期在关键命令行加 2 秒半透明黄色/青色高亮带 + 1.5× 局部放大 |
| 局部放大 | 常规放大 1.5×；关键行（`svn revert -R` 回显、`D` 状态行、脚本里 `svn delete --force --keep-local` 源码行）放大 2.0×，入点 0.2s、出点 0.2s 缓动 |
| 转场时长 | 常规切点 0 帧硬切；章节卡/转场 0.3–0.5s；AI 转场片段按 2–2.5s 使用，可再裁短 |
| 画面位移 | 截图做 Ken Burns 缓慢推拉，位移幅度 ≤5%，避免晕眩；单镜最多 1 次推拉 |
| BGM 音量 | **-20dB 左右**（讲解段落 -22～-20dB，情绪段落最高 -18dB），旁白峰值 -6dB |
| 音效音量 | -18～-12dB，只做点缀，不与旁白重叠 |
| 响度标准 | 成片整体 -16 LUFS（B站/YouTube 通用），真峰值 ≤ -1dBTP |
| 调色 | 暗部略压、对比 +5%～8%，整体偏冷；截图画面与原始终端保持一致，不要给截图加滤镜 |
| 输出 | H.264，1920×1080，60fps（或 30fps 成片统一），码率 12–20Mbps；封面单独导出 PNG |

## 7. 使用顺序建议

1. 先用第 1 节提示词生成封面底图 → 后期加标题，导出 `video/封面.png`。
2. 用第 2 节生成 5 张章节承接图，统一调色到同一套灰色/青色。
3. 用第 3 节生成片头、2 个转场、结尾片段，按 A/B 版时间轴裁剪。
4. 用第 4 节生成 A/B 两版旁白 WAV，按分镜表对齐；TTS 时长与文案标注不一致时，以「字数 ÷ 4.8」为准回听，优先删停顿而不是改稿。
5. 按第 5、6 节规范铺字幕、压 BGM、调色、输出。
