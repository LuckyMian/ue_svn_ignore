### 0.3 脚本事实清单（视频里可以说的全部范围）

1. 作用：把 **7 条规则**写入工作副本根目录的 `svn:global-ignores` 属性 —— `Binaries`、`DerivedDataCache`、`Intermediate`、`Saved`、`.vs`、`.vsconfig`、`*.sln`。
2. SVN 1.8+ 递归继承该属性；TortoiseSVN 提交对话框和 `svn status` 会跳过这些内容。
3. 参数：无参 = 询问模式（列出已被版本化的目标，问 `Y` 才移出）；`/ignore` = 只设规则；`/fix` = 设规则 + 移出版本控制；`/path "D:\WC"` = 指定工作副本根目录；`/?` = 帮助。
4. 允许工具自动定位工作副本根目录（脚本路径不是根目录时会自动切换，并提示）。
5. 白名单：脚本中部按 `call :KEEP_ADD "相对路径"` 添加；示例为 `Plugins\UnrealPackTimeVerification\Binaries\ThirdParty\Win64\TimeVerificationCrypto.dll`；会强制 `svn add`，连父目录一起加入，并给被排除目录补 `svn:ignore = *`。
6. 前置：`svn.exe` 在 PATH 中（TortoiseSVN 勾选 command line client tools，或装 Apache Subversion 命令行版）。
7. 提醒：忽略只对**未纳入版本控制**的内容有效；已提交的必须先移出版本控制并提交一次；属性改动本身也要提交一次；TortoiseSVN 里按 F5 刷新。
8. 回滚：`svn revert -R "<路径>"`（`-R` 后必须带路径；本地换过的文件先备份）。
9. 编码：脚本必须保存为 ANSI/GBK；新增被排除目录名时，规则列表与 `:IS_EXCLUDED_NAME` 两处都要同步改。

> 视频里**不要出现**上述清单以外的功能（没有图形界面、没有备份功能、没有自动提交、没有版本检测、没有云端同步）。

## 1. 视频定位

### 1.1 目标观众

- 主：用 **SVN** 管 UE 工程的程序、TA、技术美术、构建/工具链同学。
- 次：项目组长、外包团队里负责拉工程和提交的人；刚接触 UE + SVN 的新人。

### 1.2 核心信息（一句话 + 三点）

- 一句话：**一个 bat，把 7 条规则写进工作副本根目录的 `svn:global-ignores`，UE 生成物从提交列表里消失。**
- 三点：① 规则一次写入、全副本递归生效；② 已被提交的用 `/fix` 移出版本控制，本地文件不删；③ 有白名单和 `revert` 兜底，出问题能退。

### 1.3 语气与风格

- 技术、干脆、可信：先给结论，再给证据（截图/终端输出），最后给操作和风险提示。
- 不喊「家人们」，不玩「一键三连」梗；不夸大效果，不说「百分百」「彻底解决」。
- 语速稳定，句子短；每个操作都带上「为什么」，坑要明说。

## 6. 制作清单

### 6.1 需要录屏的步骤

1. **跑之前的状态**：UE 工程根目录执行 `svn status`（或 TortoiseSVN「检查修改」），滚动展示 `?` 列表；同时录提交对话框里生成物占屏的画面。
2. **`/ignore` 预览**：`ue_svn_ignore_v1.1.bat /ignore`，完整录「[1/3] 规则写入 → [2/3] 白名单 → [3/3] 递归扫描 → 验证」的全部输出。
3. **属性确认**：TortoiseSVN 右键 → 属性，选中 `svn:global-ignores`；或命令行 `svn propget svn:global-ignores "<工作副本根目录>"`，7 条规则回显。
4. **`/fix` 清理**：`ue_svn_ignore_v1.1.bat /fix`，录「开始移出版本控制 → [完成] 已标记为删除」逐行输出，并放大 `svn delete --force --keep-local`。
5. **验证**：`svn status --depth=immediates "<工作副本根目录>"` 的 `D` 列表；提交一次后再录一次干净的 `svn status`。
6. **询问模式**：双击（不带参数），录到「请输入 Y 确认，直接回车跳过」为止，不真输入（或输入 Y 再跑一遍演示移出）。
7. **白名单**：编辑脚本中部的 `call :KEEP_ADD "Plugins\UnrealPackTimeVerification\Binaries\ThirdParty\Win64\TimeVerificationCrypto.dll"` 行（这是脚本自带的格式示例，录屏时换成自己工程里真实存在的 DLL），重新运行，录该 DLL 被加入版本控制、父目录一起加入、被排除目录补 `svn:ignore = *` 的输出。
8. **回滚**：先备份本地换过的文件，再执行 `svn revert -R "<最上层显示 D 的路径>"`，录状态从 `D` 恢复正常（注意 `-R` 后必须带路径）。
9. **帮助**：`ue_svn_ignore_v1.1.bat /?`，录用法回显。
10. **注意事项特写**：脚本头部注释（编码要求、回滚说明、白名单格式）滚动 2–3 秒。
